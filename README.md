## 四、去水印参数（重新生成后必做）

生成图/视频默认带右下角「AI生成 WORKBUDDY」水印，按尺寸用 `delogo` 修复：
```bash
# 1024×1024
ffmpeg -y -i in.png -vf "delogo=x=1:y=1:w=118:h=52,delogo=x=850:y=930:w=170:h=90" out.png
# 1024×1536（竖版）
ffmpeg -y -i in.png -vf "delogo=x=880:y=1455:w=138:h=76" out.png
# 1536×1024（横版）
ffmpeg -y -i in.png -vf "delogo=x=1398:y=952:w=132:h=68" out.png
# 视频（768×768）
ffmpeg -y -i in.mp4 -vf "delogo=x=1:y=1:w=116:h=50,delogo=x=642:y=702:w=120:h=62" -c:v libx264 -crf 20 -pix_fmt yuv420p out.mp4
```
注意：`delogo` 的 x/y 不能为 0（需留 1px 边界）；输出务必写临时文件再改名，避免把输入覆盖成 0 字节。

## 六、如何恢复使用

网页里所有素材都是相对路径 `assets/xxx`，只要把 `images/` 和 `videos/` 里的文件复制回网页同级的 `assets/` 文件夹即可：
```bash
mkdir -p assets && cp _AI素材备份_20261031/images/* assets/ && cp _AI素材备份_20261031/videos/* assets/
```
`网页快照/` 里是 2026-10-31 当天四个页面的完整副本，如需回滚直接覆盖。

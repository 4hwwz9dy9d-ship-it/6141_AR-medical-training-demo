二、怎么更新到 GitHub
========================================
方式 A：在本地仓库操作（推荐）
  1. 打开本地 6141_AR-medical-training-demo 仓库文件夹
  2. 用本文件夹里的 kid.html、README.md 覆盖同名文件
  3. 把 assets/voice/ 整个文件夹复制到仓库的 assets/ 下面
     （若 assets/voice/ 已存在，直接覆盖里面的 mp3）
  4. git add .  →  git commit -m "小熊语音改为预置温柔配音"  →  git push
  5. 等 1-2 分钟刷新网页即可，网址和二维码都不用换

方式 B：GitHub 网页直接上传
  1. 打开仓库 → Add file → Upload files
  2. 把 kid.html、README.md 拖进上传区
  3. 再把 assets/voice/ 文件夹整个拖进去（GitHub 会保留目录结构）
  4. 填 Commit message 后提交
  ※ 注意：要拖「本文件夹里面的内容」，不要把本文件夹整体拖进去，
    否则仓库里会多出一层 6141_GitHub更新包... 目录，网页会找不到音频。

========================================
三、上传后怎么验证
========================================
  用微信扫原来的二维码 → 进入「小朋友」页面 → 点任意器官圆点，
  应该听到温柔女声，且与电脑上听到的完全一样。
  点「自动讲解」应能连续讲完六个器官，中间不会突然跳站。
